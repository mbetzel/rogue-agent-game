Rogue Agent Threat Cubes

During Phase 2 (Compile), cubes exit the Cube Tower into the tray. Resolve Black cubes first in Step 2A, then Red, Blue, and Green attacks simultaneously in Step 2B.

Red (Ransomware) Blocks with: Red Shield

Extorts $1 per unblocked cube. If cash is empty, 1 🔧 token automatically absorbs $1 of unpaid ransom. Any remaining unpaid ransom leaks proprietary code: lose 1 Corporate Secret per $1 unpaid!

Blue (Spyware) Blocks with: Blue Shield

Directly exfiltrates data: lose 1 Corporate Secret per unblocked cube. Reaching 0 (or fewer) Secrets immediately triggers a Total Data Breach (Patient Zero)!

Green (Malware) Blocks with: Green Shield

Corrupts systems: for each unblocked cube, move 1 Ready die to your Unpatched Zone. If you have no Ready dice left, you must instead Destroy 1 Unpatched die (returned to box)!

Black (Corruption) Step 2A: System Upgrade

Exited Black cubes advance the active Version's Corruption Track. When the 4th cell fills, the Rogue Agent upgrades to the next Version card, adding its Upgrade Payload into the Staging Cup. If v3.0 fills, Singularity is triggered!

Rogue Agent Versions Roadmap Round 1

All Rogue Agent version cards selected for this match. The AI compiles code and advances toward Singularity across these versions.

Each Version card requires 4 (2P) / 5 (3P) / 6 (4P) Black Cubes on its Corruption Track before upgrading. Filling v3.0 triggers Singularity!
