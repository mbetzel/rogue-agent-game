Rogue Agent Threat Cubes

During Phase 2: Compiler Drop & Corruption, cubes exit the Cube Tower into the tray and Black cubes resolve on the Corruption Track. Red, Blue, and Green attacks resolve simultaneously in Phase 4: Attack Resolution, after Phase 3: Income.

Red (Ransomware) Blocks with: Red Shield or Any Shield

Extorts $1 per unblocked cube. If any unpaid ransom remains (shortfall > $0), lose a flat 1 Corporate Secret dark web leak fine. Research tokens (🔬) cannot absorb ransom.

Blue (Spyware) Blocks with: Blue Shield or Any Shield

Directly exfiltrates data: lose 1 Corporate Secret per unblocked cube. Reaching 0 (or fewer) Secrets immediately triggers a Total Data Breach (Patient Zero)!

Malware (Logic Bombs) Blocks with: Green Shield or Any Shield

Corrupts systems: for each unblocked cube, move 1 active die from In Production (Income or Shields) to your Glitched Box in Under Development (or sacrifice a White Contractor). If In Production is empty, excess malware has 0 effect (no dice destroyed)!

Black (Corruption) Phase 2: Compiler Drop & Corruption

Exited Black cubes advance the active Version's Corruption Track. When the track fills, the Rogue Agent queues a Version upgrade for the start of the next round (or triggers Singularity when v3.0 fills)!
